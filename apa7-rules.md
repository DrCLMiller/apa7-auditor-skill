## UNSUBSTANTIATED CLAIMS

*Audited in Step 4b — CONDITIONAL (runs only if Q3 = YES)*  
*Claims Register is built in Step 2E using the heuristic filter below*

### Heuristic Filter (Step 2E — use to identify candidate sentences)

Flag any sentence in the body text that meets ONE OR MORE of the following criteria AND does not have a citation at the end:

| Trigger | Examples |
|---------|---------|
| Contains a specific number, statistic, or percentage | "67% of organizations...", "over 1 million devices..." |
| Contains a causal or mechanistic construction | sentences using "because," "which causes," "leads to," "results in," "due to," "enables," or "prevents" to describe how something works |
| Makes a claim about research findings or studies | "studies show," "research indicates," "evidence suggests," "according to data..." |
| Contains superlatives or absolutes about real-world patterns | "most organizations," "always," "never," "consistently," "universally" |
| Names a specific law, regulation, standard, or policy effect | "GDPR requires," "HIPAA mandates," "the NIST framework states..." |
| Describes systematic patterns or effects at scale | claims about what happens broadly across industries, populations, or time periods |

**Do NOT flag sentences that:**
- Are clearly the author's own synthesis or evaluative conclusion drawn from evidence already cited in the same paragraph
- Are explicitly framed as the author's opinion or recommendation (e.g., "The organization should consider...")
- Immediately follow a citation that covers the claim
- Are transitional or structural ("This section discusses...")

**When in doubt, flag it.** The student can decide whether a citation is warranted.

### Claim Types That REQUIRE a Citation (Step 4b evaluation)

- Specific statistics or data points ("X% of companies use...")
- Causal or mechanistic claims about how technology works
- Claims about research findings or studies
- Specific legal or regulatory claims
- Claims about systematic patterns or effects at scale

### Claim Types That May NOT Require a Citation (original analysis)

- Author's own synthesis or conclusions drawn from cited evidence
- Explicit evaluative statements framed as the author's view
- Analytical judgments, recommendations, or arguments the author is making

## REFERENCE LIST — FIELD CHECKLIST

*Used in Step 3 — apply this checklist to every reference entry from Step 2D*  
*Flag only fields that fail. Do not narrate passing fields.*

| Field | Check Question | Rule |
|-------|---------------|------|
| Author format | Every author in Last, F. I. format? Mononyms acceptable if that is the author's name? | §9.8 |
| Author count | 20 or fewer: all listed? 21+: first 19, . . ., last author? | §9.8 |
| Ampersand before final author | `&` used before the last author in a multi-author entry? | §9.8 |
| No role labels | Author field free of Dr., Prof., or similar titles? | §9.8 |
| Group/institutional author | Spelled out fully unless acronym is in common use? | §9.11 |
| Date format | Year in parentheses? Full date (Year, Month Day) for webpages with specific dates? (n.d.) if no date? | §9.15–9.17 |
| Article title case | Sentence case — only first word, first word after colon/dash, and proper nouns capitalized? NOT italicized? | §9.19 |
| Acronyms in title | Acronyms retain their standard capitalization even within sentence case? | §9.19 |
| Proper nouns in title | Proper nouns (product names, place names, etc.) capitalized in sentence case titles? | §9.19 |
| Ampersand in title | "and" used in title text (not "&") unless ampersand appears in the original source? | §9.19 |
| Navigation text in title | Title contains only the actual document title — no site breadcrumbs, taglines, or navigation artifacts? | §9.19 |
| Book / report / webpage title | Italicized? Sentence case? | §9.25 |
| Journal / periodical name | Italicized? Title case (all major words capitalized)? | §9.25 |
| Volume number | Italicized? | §9.25 |
| Issue number | NOT italicized? Enclosed in parentheses immediately after volume, no space before? | §9.25 |
| Page range | Present for journal articles? En dash (–) between page numbers? | §9.26 |
| Article number | If no page range, article number present (e.g., Article 20221157)? | §9.26 |
| Bracketed descriptor | Present for non-standard source types? (e.g., [Testimony], [Dataset], [Large language model], [Film]) | §9.21 |
| Publisher / site name | Proper organization name only — no domain extensions (.com, .org, .ai, .digital), no marketing taglines, no "- Company Name" suffixes? | §9.29, §9.34 |
| DOI format | Formatted as https://doi.org/xxxxx? Not italicized? | §9.35 |
| DOI trailing period | No period after DOI at end of reference? | §9.35 |
| URL cleanliness | No tracking parameters (e.g., utm_source=chatgpt.com)? No URL shorteners? Plain text (no blue underline / hyperlink formatting)? | §9.34 |
| Missing DOI/URL | For digital-era sources (journal articles post-~1995, webpages, online reports): is a DOI or URL present? | §9.34–9.35 |
| Alphabetical placement | Does this entry appear in the correct alphabetical position within the reference list? | §9.44 |

**When to flag a missing DOI/URL:**
- Flag as `UNVERIFIABLE — No DOI/URL` only for sources where a persistent link is reasonably expected: journal articles published after ~1995, webpages, online reports, and government documents.
- Do NOT flag books, book chapters, or print-era works (pre-internet) for lacking a DOI/URL.
- Use judgment for older journal articles (pre-1990s) — a missing DOI is not unusual and should not be flagged.

## REFERENCE TYPES — QUICK FORMAT GUIDE

### Journal Article
`Last, F. I. (Year). Title of article in sentence case. Journal Name in Title Case, Volume(issue), page–page. https://doi.org/xxxxx`

### Webpage / Online Article
`Last, F. I. (Year, Month Day). Title of page in sentence case. Site Name. https://www.url.com`

### Book
`Last, F. I. (Year). Title of book in sentence case (edition if applicable). Publisher. https://doi.org/xxxxx`

### Government Report / Legislative Document
`Organization. (Year). Title of report in sentence case. Publisher. URL`

### Legal / Statute
`Name of Act, Volume Source § Section (Year). URL`
- Bill title is italicized
- Follow APA 7 §11.5 for U.S. federal and state statutes

### Congressional / Government Testimony
`Last, F. I. (Year, Month Day). Title of testimony in sentence case [Testimony before Committee Name]. Organization. URL`

### AI Tool / Large Language Model
`Tool Name. (Year). Tool name [Large language model]. URL`

### DOI Format
- Always use URL format: `https://doi.org/xxxxx`
- Not italicized
- No period after DOI at end of reference
- If no DOI, use URL; if no URL, omit

## TABLES & FIGURES

*Audited in Step 3b — only if tables or figures are present (per Step 2F)*  
*If no tables or figures: skip Step 3b and add TABLES & FIGURES ERRORS to Clean Categories Note*

### Placement & Callout (applies to both tables and figures)

| Check | Rule |
|-------|------|
| Table or figure is called out in the body text before it appears | APA 7 §7.5 |
| Callout phrasing: e.g., "Table 1 presents..." or "(see Figure 2)" | APA 7 §7.5 |
| Table/figure placed after the callout — at bottom of page, top of next page, or on its own page | APA 7 §7.6 |
| Table/figure NOT placed in the middle of a page (not interrupting a paragraph) | APA 7 §7.6 |
| Blank line separates body text from the table/figure | APA 7 §7.6 |
| Blank line separates the end of the table/figure from the next body text | APA 7 §7.6 |
| Long tables or large figures that do not fit on one page appear on their own page | APA 7 §7.6 |

### Table-Specific Rules

| Check | Rule |
|-------|------|

| Table number line is double-spaced above the title | APA 7 §7.10 |
| Table title is italicized | APA 7 §7.10 |
| Table title is left-aligned | APA 7 §7.10 |
| Table title uses title case | APA 7 §7.10 |
| Table title appears on the line immediately below the number | APA 7 §7.10 |

## COMMON INTEGRITY FLAGS

*Used in Step 4 — REFERENCE VERIFICATION — INTEGRITY FLAGS*  
*(This section applies only when Q2 = YES and Step 4 is executed)*

| Flag | Description |
|------|-------------|
| `utm_source=chatgpt.com` in URL | Reference URL copied from ChatGPT output — AI-assisted reference generation indicator |
| Dev/staging subdomain in URL | URL not publicly accessible |
| Institution listed instead of individual author | Misattribution when individual author is identifiable |
| Wrong title | Title in reference list does not match the actual source title |
| Reference not verifiable | Possible hallucinated or ghost reference |
| Reference list entry with no in-text citation | Flag at 1+ occurrences — possible reference list padding |
| In-text citation with no reference entry | Orphaned citation |
| `UNVERIFIABLE — Paywalled` | Source exists but full verification blocked by paywall; Trinity Check partially completed |
| `UNVERIFIABLE — No DOI/URL` | No persistent link available; applies only to digital-era sources where one is expected |
